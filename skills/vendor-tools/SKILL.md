# Vendor tools

Before launching a named peer, read its matching section in
[docs/vendor-tools.md](../../docs/vendor-tools.md). Prefer the commands and
skills documented there. If the section marks a command unknown, use its linked
official vendor index and do not guess.

For another coding CLI or agent, find that vendor's official skills and commands
index, record the URL and date checked, and use only commands documented there.
Do not invent commands, slash commands, skills, or flags.
